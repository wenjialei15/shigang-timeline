# 新手运行与部署

## 最快开始：本地文件

1. 下载完整源码压缩包。
2. 右键解压到一个固定文件夹，保留 `css`、`js`、`data`、`assets` 目录。
3. 双击 `index.html`，或在浏览器中选择“打开文件”。不要直接在压缩包内打开网页。
4. 出现“史序”及时间轴即可使用。无需账号、后端或安装依赖。

文件模式下没有Service Worker，但所有应用资源就在硬盘上，可直接离线使用。不同浏览器对文件模式的存储策略不同，建议固定路径并及时备份；存储失败会显示提示。

## 本地HTTP模式（可选）

在项目目录打开终端，已安装Python 3时执行 `python -m http.server 4173`。浏览器打开 `http://localhost:4173`。关闭服务时在终端按 Ctrl+C。Node/npm不是运行网页的必需条件，只用于自动测试。

## GitHub Pages：不用写部署代码

1. 创建用于这个项目的仓库，把**本项目目录内的内容**上传到仓库根目录；确保根目录中直接有 `index.html`。
2. 打开仓库 Settings → Pages。
3. 在构建来源选择 Deploy from a branch，选择实际上传文件的分支及 `/ (root)`，保存。
4. 等待平台发布完成，访问 Pages 页面给出的地址。子路径已由相对资源路径支持。
5. 如选择 GitHub Actions 来源，则在 Actions 中手动运行随项目提供的 `Deploy GitHub Pages`；该工作流不会因普通提交自动发布。

分支方式可能同时公开仓库中的文档；不要把个人备份提交进仓库。Actions方式只复制应用必需静态文件。平台界面变更时，以平台实际设置和官方帮助为准。

## Gitee与其他静态托管

上传相同源码，若账号中存在 Pages 或静态站点服务，将含 `index.html` 的目录设为发布目录；不需要构建命令。若服务不可用，可继续本地使用或选择其他静态托管。项目不保证特定托管平台免费或持续开放。

## 推荐复习路径

1. 时间轴选择一个阶段，按事件先后浏览背景、经过、意义。
2. 先读选择考点，再看易错对比。分析题思路用于组织答案，不能代替材料分析。
3. 收藏不熟悉的事件，标记重难点，用自己的话记笔记。
4. 点击关联练习；单选选1项、多选选全部正确项。多选漏选判错，练习判定不声称完全模拟实际考试计分。
5. 分析题先输入思路，查看参考要点后自评；草稿仅本次会话保留，可将重要内容写入事件笔记长期保存。
6. 到错题复盘按阶段回看，再做对即从待复盘中移出；做错次数仍可通过历史统计反映。
7. 自认为已理解时标记“已掌握”；做对题不会自动把整段历史标记为掌握。
8. 复习后打卡。连续天数按设备当地日期计算，每天只计一次。

## 导入真题

**先查对应：**“真题考点对应”页提供2010—2025年124道题号与考点索引。每条摘要后直接列明年份、题号、题型、出处名称和链接，分析题两小问分别对应；可从知识点详情点击“历年真题索引”反查。该页不是题目全文，不能直接用摘要代替完整题目作答。

可离线阅读同目录的 [逐题对应表](EXAM_MAP_2010_2025.md)，或使用CSV/JSON。对照PDF有可核对页码时以文件页码标注。公开整理版的转录差异会在相关条目中注明，不把第三方答案当成官方评分标准。

到“我的学习”→“追加导入真题”，选择按 [数据规范](DATA.md) 编写的JSON。请仅导入有权使用的材料。当前没有提供完整真题包；不得将原创或格式样例当成真题。

导入通过后，节点自动显示关联题量；练习中心可按2010—2025年份选取套卷。此处的“套卷”是该年份已导入史纲题的练习集合，并不是完整政治试卷。导入看板不判断是否缺题。

练习中心还可查看收录审计，按年份和题型检查本机题量，查看未关联节点及疑似重复题号，并导出JSON报告。审计只检查数据结构与关联，不替代原卷及权限核验。

## 备份与迁移

- 导出学习备份：保存所有笔记、收藏、掌握、错题记录、打卡、设置和导入题库。
- 恢复学习备份：**覆盖当前记录**，先导出旧备份再恢复。校验失败时不会覆盖。
- 导出浏览器原始存档：当存档损坏或跨标签冲突时，先保存原始内容用于排查。
- 不同浏览器/设备/域名不会自动同步；在新环境恢复备份即可迁移。
- 多标签修改触发冲突后，本页不继续覆盖原存档；先导出本页临时记录，再刷新加载另一页最新记录。系统不自动合并冲突。

## 常见问题

**空白或资源找不到**：确认完整解压且目录层级没被改变。可尝试HTTP模式。查看浏览器控制台是否有文件加载失败。

**笔记不见了**：确认打开的是同一浏览器、同一域名和端口，文件模式下确认路径。检查是否使用了隐私窗口或清理过浏览器数据；从备份恢复。

**部署后断网打不开**：先在线打开站点，等待顶部显示“离线缓存已接管”；如显示“缓存已准备，刷新后启用”，在线刷新一次。须HTTPS或localhost。Service Worker被浏览器阻止时，下载源码使用文件模式。缓存尚未完成时不要提前断网。

**升级后仍见旧内容**：先备份记录，联网刷新；修改资源清单时同步升级 `sw.js` 的缓存名。不要以清理整个站点数据作为首选，因为那会删除学习记录。

**为什么索引有题而刷题仍提示没有真题**：索引提供题号、考点、关联和出处，不含题目完整材料与选项；只有导入完整题目后才能判分。124道对应索引不能计作124道可直接作答的原题。尚未取得可随项目分发的完整题库，也未完成官方原卷级逐题核验。
