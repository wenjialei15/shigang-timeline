# 真题对应索引：来源与核验边界

## 当前完成内容

2010—2025年共16个试卷年份，按本项目明确列出的史纲主线与历史交叉题范围建立124条索引：56道单选、52道多选、16道分析题。分析题另分两个小问对应，数量仍按大题计。24条标记为历史交叉考点。

每条均有项目编写的题意摘要、对应事件ID、原卷题号、题型、公开来源名称和链接。124个主要题目详页链接都在对应年份公开整理页的链接列表中确认；这不等同于每条链接在未来持续可用，也不等同于官方原卷级审定。

完整范围与逐题来源见 [对应表](EXAM_MAP_2010_2025.md)。应用内的来源紧跟每条摘要显示，刷题界面也会在题干后直接显示原创或用户导入来源。

## 来源用途

1. 真题营的逐年文字整理用于定位题号、题意和题目入口。它的科目标签、标准答案和原创解析没有直接批量复制；本项目按题意重新整理考点及关联。
2. 研招网转载的考后解析、中国教育在线和培训机构公开整理用于对照年份、范围或相关题意。标为“考情背景对照”的材料不声称包含该卷每道题原文。
3. 取得并提取了2013、2014、2015、2024、2025年的公开PDF进行补充核对。有明确题号定位时附实际PDF文件页码；2015年部分题号文本提取不完整，未编造全部页码。
4. 2018年的补充入口标明为公开回忆版；其他公开整理也没有被标为考试机构官方原卷。高校网站托管的PDF并不因此成为高校或考试机构官方发布的答案。

## 已识别的差异

- 部分文字页存在漏题，或将新文化运动标为五四运动、把六届六中全会笼统归在抗战等。索引采用具体事件节点，未直接继承这些宽泛标签。
- 2014年第29题的公开PDF中存在不同选项排列，字母答案不能跨版本直接套用；记录已注明。
- 2024年第29题的补充PDF存在文字转录混杂，另附公开文字版对照入口；记录已注明。
- 检索到的个别其他PDF出现403或404，没有把它们冒充已经成功复核的材料，也没有绕过访问限制。

## 未完成的目标

- 尚未取得并逐题核验2010—2025年的考试机构官方原卷与官方答案。
- 尚未对照报考年度官方大纲逐条审定科目归属、删去超纲题或保证范围穷尽。
- 未把124条索引当作124道可判分原题；记录明确为 `hasFullText:false`，不存在虚构的题干、选项或字母答案。

“所有年份都有对应索引”只能说明本项目的声明范围覆盖16年，不应宣传为“官方全部真题全文与答案已内置”。若获得有权使用的完整原卷文件，可继续逐题核对、导入并完善。

## 分发边界

对应关系、摘要和程序为本项目整理；外部题干、第三方解析及PDF保留各自权利状态。研究网页与PDF在 `.research/`，不进入Git或发行压缩包。交付的Markdown、CSV与JSON只有对应元数据、摘要和链接，不分发研究原文。
