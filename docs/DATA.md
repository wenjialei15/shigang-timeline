# 数据、题库与扩展规范

## 内置知识点

`data/history.js` 通过经典脚本注册 `window.HISTORY`，在 `questions.js` 之前加载。事件包含：`id/date/year/phase/title/stars/background/process/meaning/choice/analysis/confusion/sourceIds`。

阶段是复习主题而非互斥的历史时期，因此年代可以重叠。每事件当前只归一个主阶段。日期采用 `YYYY`、`YYYY-MM` 或 `YYYY-MM-DD`，按字符串排序；只有年份的事件未必发生于该年年初，编辑时尽可能补足月份。星级范围1—5，为编写者的复习建议。

**ID稳定性**：从1.1.0起，每个紧凑行以显式ID开始，格式为 `事件ID|日期|阶段ID|名称|建议星级|背景|经过|意义|选择考点|易错点`。已保留1.0.0所有ID，所以不需要迁移用户笔记。可调整行顺序；新增节点使用未占用ID（当前下一个为h091），不能重新分配或复用已发布ID。页面可导出最新ID清单。同日期事件用ID作次级排序，保持展示顺序稳定。

`data/review.js` 在history之后加载，按显式ID补充 `analysisPoints` 数组及 `HISTORY.comparisons` 对比表。24个核心事件有具体三点要点，其余事件仍提供基础分析思路。对比表的eventIds确定在哪些事件详情中显示，页面和速记共用同一份数据。

## 收录审计

练习中心的审计只统计 `origin:imported` 的题目，原创练习不计入真题关联覆盖。报告列出2010—2025年各题型数量、已关联及未关联节点，以及规范化后相同年份与题号的疑似重复项；例如 `第１题` 和 `1` 会被提示可能重复。系统不会自动删除题目。

报告不包含个人笔记、打卡或答题记录，但会包含题目ID和节点ID。所有年份保持“未核验”，不自动把填写了source、rights的材料视为已核验真题。缺少关联不意味着该节点从未考过；有关联也不表示原卷已收录完整。

## 真题导入

文件UTF-8 JSON，顶层：`{"version":1,"questions":[...]}`，空模板见 `question-bank.template.json`。下面仅为**字段说明用原创格式样例，不是2020年真实试题，不应作为真题导入发布**：

```json
{
  "id": "your-bank-2020-01",
  "year": 2020,
  "number": "1",
  "kind": "single",
  "eventIds": ["h001"],
  "stem": "【原创格式示例，非真题】中国近代史以哪一事件为起点？",
  "options": ["鸦片战争", "五四运动", "中华人民共和国成立", "辛亥革命"],
  "answer": [0],
  "explanation": "【示例解析】鸦片战争是中国近代史起点。",
  "optionNotes": ["近代史起点", "新民主主义革命开端", "新民主主义革命基本胜利", "结束君主专制制度"],
  "points": [],
  "source": "示例字段：请替换为实际原卷出处、页码或网址及版本",
  "rights": "示例字段：请替换为真实的使用权限或授权说明"
}
```

| 字段 | 约定 |
| --- | --- |
| id | 1—80字符，仅英文字母、数字、下划线和连字符，全局唯一 |
| year | 整数，2010—2025 |
| number | 原卷题号，非空字符串，最长40字符 |
| kind | `single`、`multiple`、`analysis` |
| eventIds | 1—20个存在的历史节点ID，可跨事件绑定 |
| stem / explanation | 必填文本，各不超过20000字符 |
| options | 单/多选2—8个文本选项；每项不超过5000字符 |
| answer | **从0开始**的正确选项索引，无重复；单选恰好1个，多选至少2个 |
| points | 分析题必填非空字符串数组，最多30点，每点不超过5000字符 |
| optionNotes | 可选，对应A、B、C等的辨析，最多8条 |
| source / rights | 必填来源与使用权限说明，各不超过2000字符 |
| sourceUrl | 可选出处网址；仅允许HTTP(S)，禁止嵌入用户名、密码；在题干后显示为可点击链接 |

分析题 `options:[]`、`answer:[]`，且 `points` 非空。可在stem中包含材料，换行会保留，HTML当普通文本显示，不解析图片/富文本。暂不支持共享材料、跨题组编号或自动评分。

最多3000道导入题，单文件最大10MB。与内置或既有题目重复的ID会使本次整批导入失败，不自动覆盖。修改旧题时可导出备份，离线编辑其中的imports后整体恢复，先保留原始备份。备份验证与正常导入使用相同规则。

填写来源或rights不等于项目已核实真实性或授权状态。UI统一标“用户导入”，年份看板标“未核验”。正式收录完整真题前，维护者应逐题核对原卷、答案及分发权限；不得自动把不明来源材料升级成已核验真题。

## 真题题号—知识点索引

`data/exams.js` 注册 `window.EXAM_INDEX`，与 `QUESTION_BANK` 分离。每条包括 `id/year/number/kind/topic/eventIds/scope/parts/sources/status/hasFullText`。`topic`和小问标题是项目编写的摘要；`hasFullText:false`，不得进入判分队列。

124条的编辑范围：2010—2012每年9、10、26—29、36题；2013年9、10、27—30、36题；2014—2023每年9—12、27—29、36题；2024—2025每年10—13、27—29、36题。包含历史与毛中特等课程的交叉，不声称官方学科逐题归属，也不把整张政治卷所有引用历史的题目都纳入。

`sources`为逐题出处数组，每项有name、url、locator。第一项链接至对应题目公开文字整理页；第二项为PDF、其他文字整理或标明用途的考情背景对照。PDF页码是实际文件页码；未能确认时不编造。`status:public-transcript`不表示官方原卷核验。

`parts`按分析题小问分别保存topic和eventIds；大题eventIds取这些关联的并集。考试后的事件不能冒充当年的考核史实。来源有转录问题时使用notes说明；索引不复制第三方解析或不确定的字母答案。

运行 `node scripts/export-exam-map.cjs` 重新生成docs中的Markdown、CSV、JSON。研究过程保存的网页和PDF在 `.research/`，已加入gitignore，发行打包必须排除该目录。不要把本地研究原文当作MIT内容发布。

## 本地学习状态格式

LocalStorage键为 `shixu.study.v1`。版本1包含：

```text
version: 1
marks: { [eventId]: { favorite, difficult, mastered, note } }
attempts: [{ id, correct, at: ISO时间, self: 是否分析自评 }]
checkins: [设备当地日期 YYYY-MM-DD]
imports: [已校验的用户导入题目]
theme: light | dark
font: 16 | 18 | 20
```

记录上限50000次作答，到上限后删除最早记录；这可能改变极老题目的待复盘状态，请在大规模使用前导出备份。打卡日期最多10000天。只有最新一次作答错误的题属于待复盘，答对移出；自评与客观判题分别统计。

知识与原创题库是只读本地JS文件，不全部写入LocalStorage，以避免占用有限配额。用户文件只解析为JSON且白名单复制字段，不执行脚本。动态内容统一转义；备份不加密，分享前自行检查笔记隐私。

## 新课程扩展

`HISTORY.modules` 是模块注册元数据；毛中特、马原、思法的 `enabled:false` 表示未实现。真正增加课程时，应为新课程创建独立数据命名空间、事件/概念类型、页面渲染器和状态迁移，不要只改enabled制造无效入口。当前没有通用课程插件加载器。
